# 💼 Stock Portfolio Manager - Full-Stack FinTech Application

A full-stack financial web application that enables users to track stocks, manage investment portfolios, and monitor performance. The system is designed with secure authentication, scalable backend architecture, and a clean user interface for seamless portfolio management.

---

## 🔍 Problem Statement

How can individual investors efficiently track and manage their stock portfolios in a secure, scalable, and user-friendly platform while gaining insights into their investment performance?

---

## 🏗️ Project Architecture

- Built a full-stack application using React (frontend) and Node.js (backend)  
- Designed RESTful APIs for portfolio and stock management  
- Implemented JWT-based authentication for secure access  
- Used MongoDB for flexible and scalable data storage  
- Structured backend with modular architecture (routes, models, middleware)  

---

## 🚧 Problems I Faced & How I Solved Them

- **Authentication security** → Implemented JWT with protected routes and middleware  
- **Frontend-backend communication** → Used Axios with proper error handling  
- **State management in React** → Managed component state efficiently using props and hooks  
- **Database design challenges** → Created optimized MongoDB schemas for users and portfolios  
- **Scalability** → Built modular backend structure for future enhancements

## ⚙️ Project Flow

- User registers and logs in securely using JWT authentication  
- User creates and manages stock portfolios  
- Stocks can be added or removed dynamically  
- Backend APIs process requests and manage data  
- Data is stored and retrieved from MongoDB  
- Portfolio performance is displayed on the frontend

## Installation

Clone the repository

```
git clone https://github.com/poojasukhdeve-project/stock-portfolio-manager.git
```

### Install backend

```
cd server
npm install
npm start
```

### Install frontend

```
cd client
npm install
npm start
```
